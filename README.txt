量化小程序最新版

打开方式：
1. 解压 quant-miniapp-package-fixed.zip
2. Mac 双击 start-quant-app.command
3. 鸿蒙电脑 / Linux 双击 start-quant-app.sh，或者从终端运行它
4. 输入股票后点击查询并加载行情

本版包含：
- 推荐股票里把 找主力入场股、找涨停板、233战法 合并成 智能选股。
- 智能选股会同时检查：主力入场、涨停二波、233战法，并在结果备注里写清命中条件。
- 智能选股额外显示第三阶段筑顶风险股，备注为风险观察，不作为新买推荐。
- 233战法按板块方向、股性辨识度、红肥绿瘦量价结构和当天确认信号筛选。
- 主力资金流向增加 机构偏向 / 游资偏向 / 混合中性 的参考区分。
- 第四阶段下跌风险不会生成买入提醒。
